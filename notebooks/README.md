# notebooks/

Le dossier notebooks/ contient tous les fichiers Jupyter Notebook du dépôt. Les règles de nommage appliquées :
- Noms en minuscules
- Espaces remplacés par des underscores
- Accents et caractères spéciaux supprimés
- Les fichiers conservent un préfixe numérique si présent (ex: 04_...)

Exemples :
- "04 Indexation et Selection Pandas.ipynb" -> "04_indexation_selection_pandas.ipynb"

Chaque notebook aura ses sorties supprimées (strip outputs) pour réduire la taille des commits.
